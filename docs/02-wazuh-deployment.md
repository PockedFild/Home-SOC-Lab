# Wazuh Deployment

## Objective

The objective of this stage is to deploy Wazuh on Ubuntu and connect a Windows 11 endpoint for collecting and monitoring security events.

## Wazuh Architecture

The Wazuh Agent collects security events from the Windows 11 endpoint and sends them to the Wazuh Manager.
The Wazuh Manager analyzes the collected information, while the Wazuh Indexer stores and indexes the data.
Security events and alerts can be viewed and investigated in the Wazuh Dashboard.
The lab uses the following architecture:
`Windows 11 → Wazuh Agent → Wazuh Manager → Wazuh Indexer → Wazuh Dashboard`

## Installation

I used an all-in-one deployment, where the Wazuh Manager, Indexer and Dashboard were installed on the same Ubuntu server.
First, I downloaded the official Wazuh installation script:

```bash
curl -sO https://packages.wazuh.com/4.12/wazuh-install.sh
```
Then, I started the all-in-one installation using:

```bash
sudo bash wazuh-install.sh -a
```

After the installation, I checked the status of the Wazuh services using `systemctl`:

```bash
sudo systemctl status wazuh-manager
sudo systemctl status wazuh-indexer
sudo systemctl status wazuh-dashboard
```

All three services were running successfully.

## Windows Agent Deployment

To connect the Windows 11 endpoint to Wazuh, I deployed the Wazuh Agent on the Windows VM.
During the agent configuration, I specified the IP address of the Wazuh Manager:

- Wazuh Manager IP: `192.168.0.193`
- Agent name: `SOC-WIN11`

The agent was installed using the deployment command generated by the Wazuh Dashboard.
After the installation, I started the Wazuh Agent service and verified that it was running.
The agent then successfully connected to the Wazuh Manager and appeared as **Active** in the Wazuh Dashboard.

## Verification

I verified the deployment by checking the status of the Wazuh services on Ubuntu and the status of the Windows agent in the Wazuh Dashboard.
The Wazuh Manager, Indexer and Dashboard were running, and the `SOC-WIN11` endpoint was successfully connected.
This confirmed that communication between the Windows endpoint and the Wazuh server was working correctly.

## Result

The Wazuh monitoring environment was successfully deployed.
The Windows 11 endpoint is connected to the Wazuh Manager and can send security events to the monitoring system.
The lab is now ready for security event analysis, Sysmon integration and detection testing.
